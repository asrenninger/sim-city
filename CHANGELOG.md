## [Unreleased]

### Added
- Initial package scaffolding
- Core module with SimulationConfig and MobilitySimulation classes
- Agents module with Agent, Demographics, and Population classes
- Spatial module with SyntheticCity and RealCity classes
- Models module with EPR, destination choice, and capacity mechanisms
- IO module with data loader stubs for Overture, OSM, and Census
- Metrics module with SimulationMetrics and analysis functions
- Viz module with diagnostic plotting functions
- Test suite scaffolding
- Jupyter notebook templates for tutorials
